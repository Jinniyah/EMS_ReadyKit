## Group‑Based RBAC Model

# Requirements:

* Define RBAC using Azure AD groups
* Assign roles at management group and subscription scopes
* Avoid user‑level role assignments

# Acceptance criteria

* Terraform assigns roles via groups
* Roles are scoped correctly
* ADR explains least‑privilege tradeoffs

## Azure Policy Guardrails

# Requirements:

* Required tags (Owner, CostCenter)
* Allowed regions
* Deny public IP creation (or require justification tag)

# Acceptance criteria

* Policies assigned via Terraform
* Compliance view shows enforcement
* README explains why each policy exists

## Centeralized Logging & Monitoring

# Requirements:

* Deploy Log Analytics Workspace
* Route Activity Logs / diagnostics to it
* Run and capture at least one log query

# Acceptance criteria

* Logs visible in Log Analytics
* Screenshot + query included in repo
* Runbook documents validation steps

## Secure Networking Baseline

# Requirements:

* Create VNet with at least 2 subnets
* Apply NSGs with restrictive defaults
* Enable flow logging (or traffic diagnostics)

# Acceptance criteria

* Terraform creates VNet + NSGs
* Network diagram included
* Evidence of traffic logs captured
