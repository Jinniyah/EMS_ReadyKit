# WP-03: The Hardest Problem

The hardest problem was the status computation hierarchy: a vehicle's overall readiness status has to roll up correctly from individual item checks, through compartment-level results, up through priority items like the AED and LUCAS, to a single pass/fail signal a supervisor can trust at a glance. The difficulty wasn't the logic itself but keeping it consistent — the same status rules had to hold true whether a check was in progress, saved as a draft, completed with exceptions, or viewed later in Check History, and any drift between those states would have shown a supervisor a green light on a vehicle that wasn't actually ready. I solved it by centralizing the status computation in one place in the checks router rather than letting each view compute its own version, then backing it with a dedicated persona test suite so any future change to the rules would immediately surface a broken assumption.
