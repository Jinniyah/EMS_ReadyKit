2schemas/inventory_location.py 

3Pydantic schemas for InventoryLocation. 

4 

5## Location types 

6 

7 VEHICLE — attached to one vehicle; auto-created when vehicle is created 

8 STATION_SUPPLY_ROOM — station restocking inventory; auto-created with station 

9 JUMP_BAG — portable bag shared across vehicles (e.g. Units 710/712) 

10 EQUIPMENT — standalone equipment with its own inventory (future use) 

11 

12## Create schema 

13 

14VEHICLE and STATION_SUPPLY_ROOM locations are system-managed and created 

15automatically. JUMP_BAG and EQUIPMENT locations can be created via the API 

16by Supervisors and Administrators using InventoryLocationCreate. 

17 

18The seed script uses InventoryLocationCreate to create the Jump Bag location 

19for Ambulance 712 (shared between trucks 710 and 712).
