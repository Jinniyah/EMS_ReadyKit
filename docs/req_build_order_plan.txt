## Architecture (high-level)

# Platform Foundation:

* Management Groups + Policy + RBAC + Logging + Network baseline deployed by Terraform.

* Security Onion runs as:
** A VM inside your Azure VNet
** In a monitoring subnet

* Traffic sources:
** ✅ NSG / VNet flow logs
** ✅ Linux VM auth logs
** Optional: Azure Activity Log export

# Workload:

* Web/API app + database + storage + monitoring
* SIEM integration (Security Onion) consumes selected logs/telemetry

# Validation:

* TryHackMe used as controlled simulation traffic (optional) to prove detection/log visibility

Cloud Platform (Terraform-built)
│
├── Governance (RBAC, Policy)
├── Networking (VNet, NSGs)
├── Logging (Azure Monitor / Log Analytics)
└── Security Monitoring (Security Onion SIEM)
        ↑
   Attack Simulation (TryHackMe)
